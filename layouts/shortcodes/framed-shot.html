{{- /* A tall screenshot in a browser-window frame, scrollable in place, clickable to open the full-resolution file. Exists because the image render hook (themes/ryder/layouts/_default/_markup/ render-image.html) sends every body image through `Fit "1000x1000"`, which caps the LONGEST side. On a full-page screenshot the longest side is the height, so a 3200x8670 capture is delivered at 369x1000 — a ribbon roughly a third the width of the prose column. Hugo is doing exactly what it was asked; `Fit` is simply the wrong operation for an image taller than it is wide. So this shortcode does its own processing: `Resize "x"` sets the width and lets the height follow, which is what a page capture actually wants. The frame then caps the *displayed* height and scrolls the overflow, so the reader sees a browser window showing the top of a long page and can scroll the rest without leaving the article. The theme's imageGallery lightbox is deliberately not used here. Its modal image is `max-h-full object-contain`, which fits the whole image inside the viewport — for a 1:2.7 capture that means scaling it down until it is narrower on screen than the inline version, so "open the big one" would make it smaller. A plain link to the file is better: the browser's own image viewer zooms and pans, and it works with JavaScript off. @param src page-bundle resource, e.g. "full-page-config.png" @param alt alt text (required — this is documentary UI, describe it) @param caption figcaption; optional @param label text in the window title bar, e.g. a URL; optional @param height max displayed height in px before it scrolls; default 560 @param width processing width in px; default 1400 */ -}} {{- $src := .Get "src" -}} {{- if not $src -}}{{- errorf "framed-shot: src is required (%s)" .Position -}}{{- end -}} {{- $img := $.Page.Resources.Get $src -}} {{- if not $img -}} {{- errorf "framed-shot: %q not found in the page bundle for %s" $src $.Page.RelPermalink -}} {{- end -}} {{- $width := int (.Get "width" | default 1400) -}} {{- $height := int (.Get "height" | default 560) -}} {{- $alt := .Get "alt" -}} {{- $caption := .Get "caption" -}} {{- $label := .Get "label" -}} {{- /* Never upscale: a capture narrower than $width would be blown up and go soft for no reason. */ -}} {{- if lt $img.Width $width -}}{{- $width = $img.Width -}}{{- end -}} {{- $shot := $img.Resize (printf "%dx webp" $width) -}}
