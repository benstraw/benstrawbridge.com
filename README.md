I help people turn complicated ideas into useful, durable things on the web.
Sometimes that means a fast, accessible website. Sometimes it means a custom
publishing system, an API integration, or a digital product that needs equal
parts engineering and product judgment. Usually it means asking good questions,
untangling the weird parts, and building something people can actually use.

This repository is the source for
[benstrawbridge.com](https://www.benstrawbridge.com/)—my consulting home,
project notebook, link garden, and ongoing excuse to experiment with the web.

## What I build

### Websites with a point of view

Bespoke websites for businesses, artists, photographers, musicians, and anyone
whose work deserves better than a generic template. I care about clear
information architecture, strong visual systems, accessibility, performance,
and making the finished site pleasant to maintain.

### Themes and publishing systems

I build custom Hugo themes and reusable content systems for sites that need to
be fast, flexible, and refreshingly low-drama. That work led to
[Ryder](https://github.com/arts-link/ryder), the open-source Hugo theme powering
this site and a growing collection of other projects.

### APIs, applications, and product work

I design and build API integrations, full-stack applications, and the connective
tissue between services that were never introduced properly. I can also help
shape an early idea, prioritize the right features, and guide it from “what if?”
to a tested production product.

## Arts-Link

[Arts-Link](https://www.arts-link.com/) is the first domain I ever bought and
the longest-running thread through my work. Its current incarnation explores
how thoughtful websites, open-source tools, and practical technical support can
give artists, photographers, musicians, and galleries more time for the work
that matters—and less time fighting their websites.

The [Arts-Link GitHub organization](https://github.com/arts-link) is home to
Ryder and other tools growing out of that idea.

## Let’s make something useful

Have a website that needs a grown-up? A product idea with too many moving
pieces? An API that refuses to cooperate? I’d like to hear about it.
