# Content sections

Everything under `content/` is TOML front matter (`+++`). Most pages are page
bundles (`<slug>/index.md` with images beside it); `/links/` entries are single
files.

## Creating content

```bash
hugo new content posts/my-post/index.md                         # default archetype
hugo new content --kind recipe projects/recipes/my-recipe/index.md
hugo new content links/my-link-name.md                          # links archetype
hugo new content --kind trail trails/my-trail/index.md          # trail archetype
```

Archetypes create `draft = true`. Then, before committing:

1. Write a real `description` (it's the meta description — see
   [seo/invariants.md](../seo/invariants.md)) and put `<!--more-->` after the
   first paragraph so the summary is a clean cut.
2. Generate the page's OG card: `npm run og:generate -- --only /section/slug/`
   (trail cards locally only — [seo/og-cards.md](../seo/og-cards.md)).
3. If you used a Font Awesome icon (`homeFeatureIcon` etc.), run
   `npm run test:fa-icons`.

## Sections

| Section | What it is | Notes |
| --- | --- | --- |
| `/` (`content/_index.md`) | Home: featured cards, "latest" feed, links module, latest-listening-week module | Feed excludes `params.excludedSections` and `excludedCategories = ["catalog"]`. Title is the page `<h1>` (`showHomeTitle = true`). |
| `/posts/` | Long-form writing: Hugo/Ryder how-tos, photography, music, LA, AI tooling | `listRecursive`, `loadLeaflet = true` (summaries can contain maps). Cascades `categories = ["posts"]`. |
| `/projects/` | Case studies and personal projects; holds `recipes/`, `hiking/` (legacy hiking guide), `content-adaptors/books/`, `this-website/`, `the-ryder-theme-for-hugo/`… | Grid uses `listCardType = "-image"`. |
| `/projects/recipes/` | Recipes, incl. *Mom's Family Recipes Cookbook* | Recipe archetype: schema.org Recipe fields in front matter, `ingredients` taxonomy, `{{</* recipe-ingredients-list */>}}`. |
| `/trails/` | Self-guided hiking and walking tours of LA with GPX maps | Built to [walking-tour-guide-spec.md](walking-tour-guide-spec.md); use the `new-walking-tour` command. `listCardType = "-trail"`; `tourType` picks the tile source. Section title suffix "benstrawbridge.com". |
| `/links/` | The "Link Graveyard": one file per bookmark, rendered as a filterable grid | Entries are **noindex**, have no OG card and no sitemap entry (targeted `[[cascade]]` in `_index.md`). Sorted by `date` desc — newest first, so a new link gets today's date. Subsection landings (`links/hugo/`, `links/analytics/`…) set `link_section_landing = true`. |
| `/listening/` | Spotify listening: `artists/` and `weekly/`, generated by content adaptors from `data/spotify/` | Excluded from the home feed; the latest week has its own home module. See [data/spotify-listening.md](../data/spotify-listening.md). |
| `/musical-genres/` | Taxonomy built from Spotify artist genres | ~500 terms; cloud floor and footer cap in [theme/ryder-forks.md](../theme/ryder-forks.md). |
| `/consulting/` | Services hub plus `founders/` and `companies/` door pages | Custom `layouts/consulting/{list,single}.html` and `layouts/partials/consulting/`. Offerings, stories, ways to work and the lab list live in `data/consulting.toml`; the booking URL is `params.consulting.bookingURL` ([runbook](../runbooks/consulting-booking.md)). `homeFeature*` and `weight` are set on the section page, **not** in `[cascade]`: a cascade would turn every child page into an extra home feature card (`home.html` selects on `Params.homeFeature` alone). The footer tag and genre clouds are switched off for the section with `footer.tagCloud = false` (on the hub, and in `[cascade.params.footer]` for the door pages). Q&A asides (`[[faq]]`) and `/consulting/llms.txt` are described in [seo/invariants.md](../seo/invariants.md). Don't set `layout = "list-plain"` here; it hides `layouts/consulting/list.html`. |
| `/everything-everywhere/` | Every page, one list | Custom layout. |
| `/ingredients/`, `/tags/`, `/categories/` | Taxonomy landings | `categories/catalog` is excluded from the home feed. |
| `/fineprint/` | Privacy policy, Amazon affiliate disclosure, Spotify data-use disclosure | Update when adding a new tracker, affiliate program or data source. |
| `/goals/`, `/portfolio/` | Small standalone pages | Excluded from home feed. |
| `/test/` | Theme test page | `draft = true`; only visible with `-D`. |

## Taxonomies

`[taxonomies]` in `hugo.toml`: `tag → tags`, `category → categories`,
`ingredient → ingredients`, `musical-genre → musical-genres`. Keys in
`params.taxonomyDescription` use the **singular** name.

- Tags are lowercase-kebab (`coding-agents`, `ryder-theme`). Reuse an existing
  tag before inventing one — check `public/tags/index.html` for counts.
- Categories are mostly set by section `[cascade]`, not by hand.
- Don't hand-edit `musical-genres` onto pages; it comes from Spotify data.

## Front matter you'll actually use

| Key | Effect |
| --- | --- |
| `title`, `date`, `draft`, `description`, `tags` | The basics. `lastmod` falls back to `date`. |
| `summary` | Overrides the `<!--more-->` / 100-word summary. |
| `hideAsideBar`, `showTOC` / `TocOpen` | Layout: full width, table of contents. |
| `homeFeature`, `homeFeatureWide`, `homeFeatureIcon` | Promote to the home page's feature band; icon is a Font Awesome class (must be registered). |
| `cardType`, `cardImage` (+ `cardImageAlt`, `cardImagePosition`) | Per-page card in every feed. Precedence documented in `layouts/partials/utils/card-type.html`. |
| `featured_image`, `og_image`, `og_source_image` | Imagery and OG card source; see [seo/og-cards.md](../seo/og-cards.md). |
| `aliases` | **Not a redirect** (meta refresh). Use `static/_redirects` for anything that ever ranked — [deployment/cloudflare.md](../deployment/cloudflare.md#redirects). |
| `sectionTitle` (usually via `[cascade]`) | `<title>` suffix override. Only set it when it differs from `titleShort`. |
| `robotsNoIndex`, `sitemap.disable`, `outputs` | Indexing controls, used by `/links/` entries. |
| `link_url` (links) | The external URL. A `/links/` page without one is skipped by the home feed. |

## Shortcodes

Site shortcodes in `layouts/shortcodes/`: `tour-map` (Leaflet + GPX; keep in
sync with `layouts/trails/single.ogcard.html`), `webamp`, `framed-shot`,
`float-pic`, `alltrails-referral-link`, `affiliate-link-builder-form`. The
theme supplies `picture`, `highlight`, `highlight-github`, `font-awesome`,
`alert-wrapper`, `amazon-associate-link`, `recipe-ingredients-list`,
`taxonomy-cloud` and others — see `themes/ryder/layouts/shortcodes/`.

Inline `<script>` in content or shortcodes depends on the `'unsafe-inline'`
script-src widening ([deployment/csp.md](../deployment/csp.md)). Don't add more.

## Affiliate links

`params.amazon_associate_id = "benstrawbridge-20"`. Use the theme's
`amazon-associate-link` shortcode rather than hand-built URLs, and keep
`/fineprint/amazon-affiliate-disclosure/` accurate. AllTrails referrals use
`alltrails-referral-link`.
